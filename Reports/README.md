# Completion report convention

For every future prototype and follow-up, create a new report in this directory using `Prototype_<N>_Completion_Report_YYYY-MM-DD_HHMMSS_<revision>.md`. Read the actual local clock at file creation. Record the full timestamp, UTC offset, timezone, implementation status, changed files, test commands and actual results, visual verification, and limitations in the report.

Never overwrite or rename an earlier completion report. If a filename exists, increment the revision and create exclusively. Present the new report's full absolute path in the handoff response. Preserve earlier reports as historical snapshots; later follow-ups supersede their status without editing them.
